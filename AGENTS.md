# Instructions pour agents

Ce dépôt est un skill. Toute tâche qui consiste à importer de l'audio sur une Lunii suit `SKILL.md` : lis-le en entier avant d'agir et applique ses règles cadre sans exception (copies seulement, ajout seulement, sauvegarde, test sur copie, accord explicite de l'utilisateur avant `--run`).

Pour modifier le skill lui-même, suis `CONTRIBUTING.md`.
